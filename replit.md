Run on Replit
Start the Start application workflow. It serves the project root on port 5000 with:

python3 -m http.server 5000 --bind 0.0.0.0

Open the invitation for a named guest by adding ?kpd=Guest%20Name to the preview URL.

Content
Edit invitation copy, event details, WhatsApp destination, and bank details in index.html.
Keep image filenames and their capitalization in sync with references under Images/.
Background audio is loaded from music.mp3.
